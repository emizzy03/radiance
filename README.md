# Radiance
# 🛍️ Real Shopping Website

A full-stack e-commerce platform with admin dashboard, cart, orders, and product management.

## 🔧 Stack
- Backend: Java Spring Boot, Spring Security, PostgreSQL
- Frontend: React + Tailwind CSS
- Hosting: Railway (Backend), Vercel (Frontend)
- Auth: Google OAuth (optional)
- Payments: Stripe (optional)

## 🧑‍💻 Features
- User: Browse products, add to cart, checkout
- Admin: Manage products, view orders
- Auth: Role-based access (User & Admin)

## 📦 Setup
- `cd backend && mvn spring-boot:run`
- `cd frontend && npm start`
